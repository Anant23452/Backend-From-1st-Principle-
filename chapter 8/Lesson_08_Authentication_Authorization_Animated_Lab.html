Experiment 3: Cookie flags
A cookie is a small note kept by the browser. It can carry a session ID, but the browser has rules controlling how the note is stored and sent.
Change a flag and try an action. This simulator uses a simplified cookie model.
Real cookie behavior also depends on origin, domain, path, expiry and browser rules. HttpOnly alone does not solve CSRF.


Experiment 4: Google login and delegated access
Newbert wants to let Rahul sign in with Google. The browser leaves Newbert, Google asks Rahul to authenticate, and Newbert later receives validated identity information. Separately, limited API access requires permission.
Click Next to start the authorization-code flow.
ID token or access token?
ID token: gives the client a validated identity claim. Access token: is presented to the provider's API to access approved resources. Both must be handled according to their purpose.
