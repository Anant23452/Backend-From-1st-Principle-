Start with one simple story

Newbert needs an internship API. Rahul opens the jobs list, searches for remote internships, applies to one job, then checks his application. If every API route follows different rules, Rahul's frontend developer must guess what to send.

REST API design is planning a predictable agreement: which URL identifies the information, which HTTP method expresses the action, what JSON should be sent, and what response is returned.
