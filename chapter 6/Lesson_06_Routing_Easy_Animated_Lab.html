The method says WHAT

GET usually retrieves information. POST often submits new information. They express the request's intent.

The route says WHERE

/api/books means “book resources.” /api/users/123 means “the user identified by 123.”

Experiment 2

Path parameter vs query parameter

Imagine opening a student profile and then searching among internship opportunities. One value identifies which student; the other controls how to search.

Identify one user

Search with extra instructions

Teacher's memory rule: A path parameter describes a resource within the path, while a query parameter supplies search, filter, sorting or pagination options. In Express they are available through req.params and req.query.
