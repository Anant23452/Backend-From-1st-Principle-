Experiment 02
Methods and status codes
A method expresses your intention. A status code tells you the outcome. Trigger realistic backend situations and learn what the client should do.


Experiment 03
CORS and the OPTIONS preflight
Your browser runs on localhost:5173 and your API runs on localhost:5000. Set the method and headers; then let the browser decide if it needs preflight and whether JavaScript may read the response.
CORS controls what browser JavaScript can read and which preflighted requests proceed. It is not a replacement for login verification or role-based authorization.

Experiment 05
Content negotiation and compression
The client expresses preferences. The server chooses a representation it can actually provide.
Try requesting HTML instead of JSON. Compare Accept versus Content-Type.


Experiment 06
Multipart request and streaming response
See two different ideas: separating a file upload into named parts, and streaming events back progressively over one response.
multipart/form-data
One HTTP request can contain text fields and a file, with boundaries separating each part.
text/event-stream
One long-lived HTTP response can progressively deliver multiple events.
Multipart form-data and S3 multipart upload are different things. SSE is one particular type of streaming, not the only way to stream bytes.
