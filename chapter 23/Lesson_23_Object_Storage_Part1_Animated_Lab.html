Interactive experiment 5

Signed URL vs policy-based upload

The teacher demonstrates that a signed PUT can delegate a method and key without automatically enforcing a maximum file size. A signed POST policy can enforce content-length-range and field conditions.

Implementation reminders

Never expose secret keys in React. Treat signed URLs as bearer capabilities. Verify uploaded content server-side before publishing. A MIME header alone cannot prove that uploaded bytes are an image.
